# Pencarian sumber nyata F4 (terpisah dari API runtime)

**Tanggal pemeriksaan:** 3 November 2026, melalui pencarian web publik. **Pencarian ini bukan keberhasilan adapter HTTP Python.**

1. **BPS, Statistik Telekomunikasi Indonesia 2024**, tanggal rilis 29 Agustus 2025, katalog 8305002, nomor publikasi 06300.25007. Halaman publikasi menyatakan berdasarkan Susenas 2024, 72,78% penduduk Indonesia mengakses internet pada 2024, dibanding 69,21% pada 2023. Sumber: https://www.bps.go.id/id/publication/2025/08/29/beaa2be400eda6ce6c636ef8/telecommunication-statistics-in-indonesia-2024.html . Angka pada contoh CSV `examples/f4_public_metadata/bps_internet_2024_manual_excerpt.csv` **ditranskripsi manual dari abstraksi laman**, bukan diunduh melalui WebAPI. Status tetap **belum dapat diverifikasi** sampai definisi indikator, halaman tabel, bobot dan rincian metode diperiksa pada publikasi PDF asli.
2. **BPS, Statistik Telekomunikasi Indonesia 2025**, terbit 31 Agustus 2026; memuat hasil Susenas, Podes dan data administrasi. Sumber: https://www.bps.go.id/id/publication/2026/08/31/49c6f2edbe4fdc176175d833/statistik-telekomunikasi-indonesia-2025.html . Tidak ada angka 2025 yang dicatat di contoh karena belum diperiksa pada tabel lengkap.
3. **World Bank, Individuals using the Internet (% of population), Indonesia**, halaman web menampilkan sekitar 73% untuk 2024, dibulatkan. Sumber: https://data.worldbank.org/indicator/IT.NET.USER.ZS?locations=ID . Sumber aslinya adalah ITU menurut laman tersebut. Nilai tampilan ini **tidak disamakan** dengan nilai BPS karena sumber, definisi, pembulatan dan prosedur statistik perlu diperiksa sebelum perbandingan.
4. **World Bank Indicators API V2**, dokumentasi https://datahelpdesk.worldbank.org/knowledgebase/articles/889392 dan https://datahelpdesk.worldbank.org/knowledgebase/articles/898581-api-basic-call-structures . API JSON V2 tersedia tanpa API key menurut dokumentasi. Percobaan langsung menggunakan `requests` dalam runtime ini gagal karena DNS; lihat `reports/F4_LIVE_API_ATTEMPT.json`.
5. **BPS WebAPI**, portal https://webapi.bps.go.id/developer/ mewajibkan registrasi pengguna. Adapter BPS **NOT_RUN**; tidak ada token dibuat atau digunakan.

**Batas inferensi:** persentase akses internet nasional dapat menjadi konteks komunikasi digital di Indonesia, tetapi tidak membuktikan perilaku seorang mahasiswa, krisis di satu perusahaan, atau hubungan sebab-akibat tertentu.
