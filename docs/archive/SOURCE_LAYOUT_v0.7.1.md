# Source layout notes, v0.7.1

The source distribution was reorganized for easier GitHub navigation. Original research runtime and all ten canonical SKILL.md folders remain unchanged.

- Install guides moved from root into docs/{en,id}/install/.
- Quick-start documents moved into docs/{en,id}/.
- Release notes, migration notes, and version-specific changelogs moved into docs/{en,id}/releases or migrations.
- Required reports were restored from the audited v0.7.1 release package because earlier source-only ZIP omitted them and left broken links.
- Existing test history remains separate from current release results.
- Generated build outputs and licensed/private research materials are not included in the GitHub source package.
