# Serah-terima: F4 alpha ke stabilisasi F4

Baseline yang perlu diunggah pada percakapan berikutnya: `EPISTARIUM_FASE_IV_ALPHA_v0.4.0.zip`. Mulai dari audit ZIP, kontrak, tes 198, dan laporan `reports/F4_GATE_v0.4.0-alpha.md`. Jangan menganggap semua klaim sudah lulus pada perangkat baru.

Identitas: EPISTARIUM Research Intelligences, sepuluh persona. Jorhas The Path Finder mengorkestrasi Vanlan, Liora, Agresa, Retho, Domares, Synthia, Ideon, Quilo, dan Huxley. Mode utama `PATH_FINDING`, mode tambahan `FULL_RESEARCH`. Ideon ORIGO (QUICK_MAP/ELABORATE_21/BLUEPRINT/REVISION), **bukan** RMC default. Dokumentasi publik netral dari identitas personal.

Bukti: tes regresi F1-F3 151/151; tes F4 47/47; adapter World Bank live BLOCKED DNS; empat provider lain source-plan NOT_RUN; enam native platform NOT RUN. BPS web source ditemukan melalui pencarian publik, dua nilai 2023/2024 ditranskripsi manual dan diproses sebagai CSV lokal dengan status belum dapat diverifikasi.

Prioritas stabilisasi: (1) audit kualitas penerapan sumber resmi, (2) validasi struktur JSON dengan schema, (3) mitigasi DNS rebinding dan robots/Terms, (4) adapter tambahan BPS/WHO/GDELT dengan data contoh legal, (5) integrasi ke ORIGO dengan evidence handoff yang tidak mengubah bukti menjadi final, (6) validasi pengguna nonteknis di macOS/Windows, (7) lisensi kode/dependensi, (8) privacy scan, (9) kebutuhan integrasi pembacaan semantik yang ditinjau manusia.
