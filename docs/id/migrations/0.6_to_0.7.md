# Migrasi v0.6.0 ke v0.7.0

Pembaruan ini menyiapkan rilis. Sepuluh slug persona, perintah CLI, status bukti, kunci schema, dan handoff F1 hingga F4 dipertahankan.
Jalur kanonis .agents/skills tidak berubah. Inggris dan Indonesia tetap memakai satu implementasi.
Karya orisinal kini memiliki pemberitahuan MIT. Lisensi PyMuPDF tetap terpisah dan gerbang rilis publik berstatus HOLD.

<!-- section: steps -->
## Langkah migrasi

1. Cadangkan masukan, konfigurasi, dan keluaran privat di luar proyek lama.
2. Ekstrak kandidat ke direktori terpisah. Pertahankan pohon folder lengkap.
3. Buat venv baru. Pasang kandidat melalui panduan OS.
4. Jalankan doctor dan pastikan versi 0.7.0 serta sepuluh skill pada root proyek.
5. Jalankan Penelitian Pertama dengan folder keluaran baru. Pisahkan contoh sintetis dari pekerjaan empiris.
6. Tinjau hak sumber sebelum memakai ulang konfigurasi data langsung lama.
7. Buat adaptor Claude hanya jika diperlukan. Ulangi --apply setelah perubahan skill kanonis.
8. Periksa lisensi dan kesiapan sebelum meminta publikasi.

Batas PDF kini >=1.28.2,<2. Jangan menurunkan versi pada lingkungan campuran 2.x yang sama.
Contoh angka BPS publik tidak lagi menyatakan hak terkonfirmasi secara default. Tetapkan hak hanya setelah memeriksa penggunaan yang diizinkan.
Keluaran pengguna tidak dimigrasikan atau ditimpa secara otomatis.

Jalankan ulang Domares dan Synthia untuk rekaman lama yang field printed_page-nya berisi string literal printed_page.
Pertahankan artefak lama untuk keterlacakan. Jangan menyunting hash auditnya secara diam-diam.
ORIGO v1.0.0 menunjukkan protokol pemetaannya. Versi paket EPISTARIUM tetap 0.7.0.

## Pemeriksaan kontrak

Suite regresi rilis mengulang pemeriksaan halaman/koordinat/highlight, identitas sumber, pelestarian status, dan keluaran tahap F1 hingga F4.
Kedua bahasa mempertahankan enum kanonis serta token sumber yang sama. Label tampilan tetap terpisah dari data pertukaran.
Nomor versi historis dalam changelog dan laporan baseline tetap bersifat historis. Angka itu bukan metadata paket aktif yang tertinggal.
