# EPISTARIUM v0.7.0 Release Candidate

Explore. Analyze. Verify.

Modular AI Research Skills. English dan Bahasa Indonesia. Sepuluh persona, satu basis kode.
Kandidat ini untuk pemeriksaan pemilik. Rekomendasi rilis publik: HOLD. Paket belum stable v1.0.

<!-- section: changes -->
## Perubahan

README kini mendahulukan pemasangan, pilihan bahasa, katalog sepuluh persona, mode penelitian, dan batas bukti.
Tiga panduan OS serta sepuluh panduan platform membedakan dukungan terdokumentasi, adaptor, penggunaan manual, dan aktivasi yang belum diuji.
Tutorial bahasa alami mencakup sepuluh persona. Penelitian Pertama hanya memakai contoh sintetis dalam paket.
Adaptor proyek Claude mencatat hash dan menolak penimpaan berkas bukan miliknya atau berkas yang telah berubah.
Pemeriksaan dokumentasi mencakup tautan lokal dan cakupan bagian berpasangan. CI disiapkan untuk tiga OS dan tiga versi Python.
MIT kini mencakup karya orisinal dengan pemegang hak yang disebutkan. Pemberitahuan pihak ketiga mempertahankan lisensi terpisah dan atribusi SimpleEnglish.

Parsing XML diperkuat dengan defusedxml. Konfigurasi BPS lama tidak lagi menyatakan hak penggunaan ulang terkonfirmasi secara default.

Domares kini membaca nilai halaman cetak dengan benar. Synthia menerima nilai halaman atau null, bukan nama kunci dictionary.
ORIGO menyediakan ruang di atas footer. Pemeriksaan render dua bahasa mencakup contoh panjang yang disertakan.

Modul PDF kini memakai impor pymupdf upstream. Doctor mempertahankan keluaran JSON bersih pada proses baru.

<!-- section: dependencies -->
## Keputusan dependensi dan lisensi

PyMuPDF dibatasi menjadi >=1.28.2,<2 dan tetap wajib. Ketentuan AGPL/komersialnya tetap berlaku.
Tidak ada klaim bahwa pengemasan opsional atau batas proses menyelesaikan kewajiban. Fitur PDF tidak dihapus untuk memperoleh label MIT.
Rencana distribusi publik runtime gabungan berstatus BLOCKED sampai jalur AGPL, perjanjian komersial, atau pengganti permisif teruji ditelaah.
Baca [audit lisensi](../../../reports/v0.7.0/LICENSING_AUDIT.id.md). Seluruh runtime beserta dependensinya tidak hanya berlisensi MIT.

<!-- section: install -->
## Instalasi dan migrasi

Gunakan EPISTARIUM_v0.7.0_RELEASE_CANDIDATE.zip yang disertakan. Tidak ada asumsi URL repositori atau rilis publik.
Ikuti panduan [Windows](../install/windows.md), [macOS](../install/macos.md), atau [Linux](../install/linux.md), lalu jalankan doctor.
Gunakan venv baru agar lingkungan PDF lama tanpa batas versi tidak bercampur dengan kandidat ini.
Wheel berisi pustaka Python dan CLI. Gunakan ZIP lengkap untuk skill serta dokumen bersama.
Baca [migrasi](../migrations/0.6_to_0.7.md) sebelum menyalin konfigurasi penelitian.

<!-- section: evidence -->
## Validasi dan batas yang diketahui

Baca [TEST_RESULTS](../../../reports/v0.7.0/TEST_RESULTS.id.md) untuk jumlah tes final, perintah, dan log.
Pemeriksaan CLI Linux dan artefak merupakan bukti lokal. Windows, macOS, dan CI remote masih NOT_RUN.
Sepuluh pemeriksaan aktivasi host native masih NOT_RUN. Verifikasi pemasangan native Windsurf saat ini BLOCKED karena dokumentasi tidak dapat diakses.
Provider langsung, kualitas penalaran model, validitas ilmiah, dan dukungan semantik klaim tidak dibuktikan oleh tes regresi.
Full Research tetap PARTIAL. OCR, pengambilan otomatis melewati pembatas akses, dan parsing sitasi tanpa batas tidak disediakan.
Laporkan bug memakai langkah yang disamarkan dalam [CONTRIBUTING](../../../CONTRIBUTING.id.md). Jangan melampirkan penelitian privat sebagai reproduksi publik.
