# Evidence rules

EPISTARIUM records where evidence comes from and what a process actually did. Provenance means the recorded origin of a data item.

Keep execution, artifact completion, source identity, text matching, and support for meaning separate. A successful function call cannot establish a scientific finding.

A source title, DOI match, official-looking URL, or exact quote location is insufficient for a claim of substantive support.

The Pathfinder ledger holds input assessments at belum dapat diverifikasi. The source assessment stays in source_claimed_status. The English display label is not yet verifiable.

Vanlan can import human decisions through a review file. Each decision needs a status, reviewer, and reason. The agent cannot invent approval.

Keep source words, numbers, dates, names, DOI values, and uncertainty intact. The English language mode translates program text, not research evidence.

Record the PDF hash and page location. A hash is a file fingerprint. If the PDF changes, stop the dependent reading.

Record PDF pages separately from printed pages. Keep an unknown printed page null. Do not infer a page from a year or article number.

Read a candidate passage in its original context before using it. Missing keyword matches do not establish that an idea or finding is absent.

Separate publication dates from event dates. A five-year phenomenon window does not automatically exclude classical theory or method sources.

Keep national context separate from local case estimates. Do not pool different populations, units, definitions, or sampling designs.

A survey with voluntary or purposive participation does not automatically represent a national population. Google Trends and news coverage do not measure event prevalence.

Keep every source_id linked to a retained source record. Preserve source aliases and access attempts after deduplication. Use article_id across literature stages.

Read the [status glossary](STATUS_GLOSSARY.md) and [workflow](WORKFLOW.md) before promoting any result into a research argument.
