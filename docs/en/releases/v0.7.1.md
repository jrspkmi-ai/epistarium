## Changes

The README now leads with installation, language choices, the ten-persona catalog, research modes, and evidence boundaries.
Three OS guides and ten platform guides distinguish documented support, adapters, manual use, and untested activation.
Natural-language tutorials cover all ten personas. First Research uses only included synthetic examples.
The Claude project adapter records hashes and refuses to overwrite unowned or changed files.
Documentation checks cover local links and paired section scope. CI is prepared for three OS names and three Python versions.
MIT now covers original work with an explicit rights holder. Third-party notices preserve separate licenses and SimpleEnglish attribution.

XML parsing adds defusedxml hardening. The legacy BPS configuration no longer asserts confirmed reuse rights by default.

Domares now reads printed-page values correctly. Synthia receives a real page value or null, rather than a dictionary key.
ORIGO reserves space above its footer. A two-language render check covers the supplied long example.

PDF modules now use the upstream pymupdf import. Doctor keeps clean JSON output in a fresh process.

## Dependency and licensing decision

PyMuPDF is bounded to >=1.28.2,<2 and remains required. It keeps its AGPL/commercial terms.
No claim is made that optional packaging or a process boundary solves its obligations. No PDF features were removed to obtain an MIT label.
The combined-runtime public distribution plan is BLOCKED pending a reviewed AGPL route, commercial agreement, or tested permissive replacement.
Read [the licensing audit](../../../reports/v0.7.0/LICENSING_AUDIT.md). The entire runtime and its dependencies are not MIT-only.
