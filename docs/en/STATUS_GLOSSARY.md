# Status glossary

The data contracts keep their existing status values. English reports use readable labels. A language choice cannot raise the strength of evidence.

| Canonical evidence value | English label |
|---|---|
| terverifikasi | Verified |
| didukung sebagian | Partly supported |
| bertentangan | Contradicted |
| tidak ditemukan | Not found |
| belum dapat diverifikasi | Not yet verifiable |
| inferensi peneliti/AI | Researcher/AI inference |
| hipotesis atau rekomendasi | Hypothesis or recommendation |

The first four values require their stated scope and supporting review. A value supplied by an external source is not an EPISTARIUM human decision.

| Domain | Value | Meaning |
|---|---|---|
| Execution | SUCCESS | The stage produced its required artifacts |
| Execution | PARTIAL | Part of the requested scope is available |
| Execution | BLOCKED | Input, access, environment, or required artifacts prevent completion |
| Execution | FAILED | The stage failed outside an ordinary blocked condition |
| Execution | NOT_RUN | The stage was not called |
| Artifacts | COMPLETE / INCOMPLETE | Required stage files are complete or incomplete |
| Artifacts | NOT_REQUESTED | The stage was not requested or its input was absent |
| Huxley | MATCHED | A citation and reference match within the parser scope |
| Domares | machine_fulltext_extracted | Machine-readable PDF text was extracted |
| Ideon | DRAFT_PERLU_REVIEW_MANUSIA | Draft for human review |
| Quilo | NOT_ASSESSED | Meaning has not been assessed |

Full Research keeps its research status PARTIAL. Its stage results describe execution and artifact completion. This does not establish final research findings.
