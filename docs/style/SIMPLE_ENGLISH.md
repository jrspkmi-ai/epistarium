# English writing rules

EPISTARIUM uses the Plain mode of [SimpleEnglish](https://github.com/AminBlg/SimpleEnglish), version 2.1.1. The source record and MIT notice are in `third_party/SimpleEnglish/`.

Write instructions with one action per sentence. Put a condition before its action. Use at most 20 words in an instruction.

Write descriptions with simple tenses and an active voice. Use at most 25 words in a descriptive sentence. Keep one topic per paragraph.

Use common words and complete grammar. Use American spelling. Define a new concept in fewer than ten words at first use.

State the fact directly. Remove decorative emphasis and claims of importance without a stated basis. Avoid contractions, semicolons, and em dashes.

Use must for a requirement. Use can for an available action. State missing knowledge explicitly without raising the certainty of a scientific claim.

Use formatting only for structure. Keep steps and comparison tables when the task needs them. In a normal English chat reply, use prose without headings, lists, bold, or tables. A required command can use a code block.

Keep code, commands, file paths, identifiers, numbers, dates, quotes, and source text unchanged. A language choice never authorizes translation of research evidence.

Keep technical distinctions. A paradigm is not a model. A literal text match does not establish support for a claim.

The English Quilo preset flags possible writing issues. It does not prove that prose follows every rule. Human reading remains required.

These rules adapt an independent project. No claim of ASD-STE100 certification is made. This file does not install SimpleEnglish as another EPISTARIUM persona.
