# ORIGO Acceptance Checklist (untuk F3 Stabilization)

- [ ] A01 DOCX berhasil dibuat dan bisa dibuka dengan `python-docx` serta Word/LibreOffice.
- [ ] A02 Heading peta tepat enam, berurutan vertikal tanpa tabel enam bidang.
- [ ] A03 Default tiga judul substantif, tidak sekadar sinonim.
- [ ] A04 Q01-Q21 muncul tepat satu kali dan berurutan setelah bagian pemetaan.
- [ ] A05 Mode Quick tidak memaksa esai untuk 21 langkah.
- [ ] A06 Input teori pengguna dipertahankan.
- [ ] A07 Ketidaktersediaan data membuat opsi metode diberi catatan kendala.
- [ ] A08 Novelty masih bersifat potensi sebelum kajian terdahulu diperiksa.
- [ ] A09 Mode ELABORATE_21 tidak mengarang DOI, sumber, angka, hasil.
- [ ] A10 Revisi teori memperbarui fokus/metode/judul yang terdampak tanpa menghapus fenomena.
- [ ] A11 Output DOCX berhasil dirender dan diperiksa tidak ada teks terpotong.
- [ ] A12 Tidak ada berkas RMC pihak lain dalam paket skill; format visual bukan salinan.
- [ ] A13 Kode tidak menampilkan kemampuan yang belum dibuat sebagai fitur PASS.
- [ ] A14 Tes regresi F3 sebelumnya tetap dijalankan dan masalah Huxley/Quilo tidak ditutup tanpa bukti.
