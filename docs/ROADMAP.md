# Arah pengembangan setelah v0.6.0

Pilihan bahasa ID/EN sudah tersedia dalam sepuluh persona yang sama. Cakupan implementasi dan uji aktual tercatat di reports/v0.6.0/RELEASE_GATE.md.

Tahap berikut meliputi uji native perangkat/host pengguna, evaluasi ilmiah pada korpus berizin, peninjauan akses provider live, serta keputusan lisensi sebelum distribusi publik.

Provider tambahan, adjudikasi AI, OCR, UI review dan jembatan otomatis Huxley ke Vanlan tetap belum diimplementasikan. Versi bahasa tidak mengubah batas bukti tersebut.
