# Licensing resolution, v0.7.1

The original EPISTARIUM code remains MIT. The production runtime now imports pypdfium2 and pypdf; `PyMuPDF` is absent from required dependencies and production imports. The project wheel and ZIP do not vendor PDFium or other dependency wheels. This is a technical resolution of the prior combined-runtime blocker for the stated source/wheel distribution pattern, subject to the separate terms of installed dependencies. It is not a legal opinion.

The installed Linux Python 3.12 environment has pypdfium2 5.14.0 and pypdf 6.21.4. pypdfium2 metadata lists no mandatory transitive Python distributions. Its Linux x64 wheel contains Apache-2.0, BSD-3-Clause, CC-BY-4.0 license files and 15 component files under `data/linux_x64/BUILD_LICENSES/`, including PDFium, Freetype, ICU, JPEG, OpenJPEG, PNG, zlib, and other notices. The pypdf wheel declares BSD-3-Clause and includes LICENSE. CC-BY applies to pypdfium2 documentation/examples, not an assertion that PDFium binaries are CC-BY. The exact binary build, architecture, and native linkage can differ by OS and wheel. Inspect the installed wheel and preserve all applicable notices when redistributing it. Consult [pypdfium2's official license explanation](https://pypi.org/project/pypdfium2/) and [pypdf's repository](https://github.com/py-pdf/pypdf).

Inherited tests still create and inspect PDFs with PyMuPDF. The `test` extra therefore installs it explicitly. This is a **development-only** AGPL/commercial dependency and is excluded from the ordinary install's dependency closure. Do not package the development environment under an MIT-only label. If that test environment is distributed, review its separate obligations. Future work can replace those fixtures and remove the test extra.

No claim is made that a module boundary or optional marker exempts an AGPL combined distribution. The abandoned v0.7.0 full runtime remains HOLD_TERBATAS for its own distribution model. The current project source/wheel gate is GO_BERSYARAT on accurate notices, no bundled binary wheel, and honest OS support claims.
