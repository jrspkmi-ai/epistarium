## Sumber Python dan OS

[Windows](https://docs.python.org/3/using/windows.html) · [macOS](https://docs.python.org/3/using/mac.html) · [venv](https://docs.python.org/3/library/venv.html)

[Unduhan Python](https://www.python.org/downloads/) · [Python Ubuntu](https://documentation.ubuntu.com/ubuntu-for-developers/howto/python-setup/) · [venv Debian](https://packages.debian.org/stable/python3-venv)

Panduan memakai interpreter venv eksplisit. Windows menghindari Activate.ps1 dan perubahan execution policy global.
Panduan macOS membedakan Intel dan Apple Silicon. Hak istimewa Linux dibatasi untuk pemasangan paket OS yang belum tersedia.
Tidak ada perintah pengelola paket yang belum diverifikasi untuk distribusi lain.
